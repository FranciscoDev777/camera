
# Camera PFE — Captura Identificada
## Integrantes
- Integrante 1: Francisco Gabriel

## Descrição
Aplicação web desenvolvida para a atividade sobre Câmera, Canvas e MediaDevices.
A aplicação permite acessar a câmera do dispositivo, visualizar o vídeo em tempo real, capturar uma fotografia, aplicar alguns efeito e gravar uma identificação com a data e a hora diretamente na imagem.
A fotografia processada pode ser visualizada e baixada em formato PNG.

## Arquivos do projeto
- index.html: estrutura da página.
- style.css: estilos e aparência da interface.
- script.js: acesso à câmera, captura e processamento da imagem.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- MediaDevices e getUserMedia()
- Canvas 2D
- Eventos JavaScript
- Manipulação do DOM
- MediaStream e getTracks()
- Intl.DateTimeFormat()

## Recursos implementados
- Solicitação de permissão para acessar a câmera.
- Exibição do vídeo em tempo real.
- Captura de fotografias reais.
- Aplicação do efeito sépia.
- Identificação textual gravada na imagem.
- Data e hora gravadas na imagem.
- Visualização da fotografia processada.
- Download da imagem em PNG.
- Botões para ligar e desligar a câmera.
- Encerramento das faixas do stream com track.stop().
- Mensagens para permissão negada ou câmera indisponível.
